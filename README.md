# RTL Workshop

Welcome to the *RTL Workshop*, a practical, hands-on learning series designed to explore **Verilog RTL design, simulation, synthesis, and digital circuit optimization**.
This repository is structured into multiple days, each containing detailed labs, code examples, and guided explanations to strengthen your understanding.

## 📘 About This Workshop

This workshop is tailored for students, hobbyists, and engineers aiming to gain both theoretical and practical knowledge in:

* Writing and simulating Verilog RTL designs
* Using *Icarus Verilog* and *GTKWave* for simulation and waveform debugging
* Performing logic synthesis with *Yosys* and the *Sky130 open-source PDK*
* Understanding testbenches, timing libraries, and flip-flop coding methodologies
* Identifying and resolving synthesis-simulation mismatches
* Applying digital design optimization techniques for efficient hardware design
* Building confidence in industry-relevant open-source ASIC design workflows

---

## 🛠 Prerequisites

Before diving in, ensure that you have:

* A basic understanding of digital logic circuits (gates, muxes, FFs, counters, etc.)
* Familiarity with Linux command-line tools
* Access to a Linux-based system (native, WSL, or virtual machine)
* Installed tools: *git, iverilog, gtkwave, yosys*
* A text/code editor (*VS Code* recommended with Verilog extensions)
* Optional but helpful: prior exposure to C programming or basic HDL concepts

---

## 📂 Workshop Structure

The workshop progresses over several days with increasing depth:

* **Day 1:** Fundamentals of Verilog RTL Design & Synthesis
* **Day 2:** Timing Libraries, Synthesis Strategies, and Flip-Flop Coding Styles
* **Day 3:** Combinational and Sequential Logic Optimization
* **Day 4:** Gate-Level Simulation (GLS), Blocking vs. Non-Blocking Assignments, and Synthesis-Simulation Mismatches
* **Day 5:** Advanced Optimization Techniques in Synthesis

Each day includes:

* Conceptual explanations with diagrams
* Step-by-step practical labs (with Verilog code and screenshots)
* Debugging tips and industry best practices
* Additional exercises for self-practice

---

## 🎯 Learning Outcomes

By the end of this workshop, participants will be able to:

* Write, simulate, and synthesize Verilog RTL modules confidently
* Analyze waveforms to debug digital designs effectively
* Understand timing constraints and optimization in digital design
* Differentiate between behavioral, RTL, and gate-level coding
* Apply open-source EDA tools for ASIC design flows
* Develop a strong foundation for advanced RISC-V based projects
